## 📋 Deployment Steps Summary

### **Step 1: Push to GitHub** (5 min)
```bash
git init
git add .
git commit -m "Ready for deployment"
git remote add origin https://github.com/YOUR_USERNAME/knowyourcampus.git
git push -u origin main
```

### **Step 2: Deploy Backend to Railway** (10 min)
1. Go to https://railway.app
2. Sign up with GitHub
3. Create new project from your repository
4. Add MySQL database
5. Set environment variables
6. Deploy automatically
7. Copy backend URL

### **Step 3: Deploy Frontend to Vercel** (5 min)
1. Go to https://vercel.com
2. Sign up with GitHub
3. Import your repository
4. Set root directory to `frontend`
5. Add environment variable: `VITE_API_URL`
6. Deploy
7. Copy frontend URL

### **Step 4: Update CORS** (2 min)
1. Add Vercel URL to Railway environment variables
2. Redeploy backend

### **Step 5: Test & Submit to Google** (15 min)
1. Test all features
2. Submit to Google Search Console
3. Submit sitemap
4. Done! 🎉
