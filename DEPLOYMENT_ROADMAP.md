## 🎯 Phase 1: Domain Purchase (30 min)

### **Step 1: Buy Domain from Hostinger**
- [ ] Go to https://www.hostinger.in
- [ ] Search for domain (e.g., `knowyourcampus.com`)
- [ ] Purchase domain (₹699-999/year)
- [ ] Receive confirmation email

**Guide**: `HOSTINGER_DOMAIN_SETUP.md` (Section 1)

---

## 🚀 Phase 2: Backend Deployment (15 min)

### **Step 2: Deploy to Railway**
- [ ] Go to https://railway.app
- [ ] Sign up with GitHub
- [ ] Push code to GitHub first
- [ ] Create new project from GitHub repo
- [ ] Add MySQL database
- [ ] Set environment variables
- [ ] Copy backend URL

**Guide**: `QUICK_DEPLOY.md` (Section 2)

---

## 🌐 Phase 3: Frontend Deployment (10 min)

### **Step 3: Deploy to Vercel**
- [ ] Go to https://vercel.com
- [ ] Sign up with GitHub
- [ ] Import GitHub repository
- [ ] Set root directory: `frontend`
- [ ] Add env variable: `VITE_API_URL`
- [ ] Deploy
- [ ] Copy Vercel URL

**Guide**: `QUICK_DEPLOY.md` (Section 3)

---

## 🔗 Phase 4: Domain Connection (15 min)

### **Step 4: Connect Domain to Vercel**
- [ ] Vercel → Settings → Domains
- [ ] Add your domain
- [ ] Get DNS records from Vercel
- [ ] Go to Hostinger DNS settings
- [ ] Add A record: `76.76.21.21`
- [ ] Add CNAME: `cname.vercel-dns.com`
- [ ] Save changes

**Guide**: `HOSTINGER_DOMAIN_SETUP.md` (Section 3-4)

---

## ⏰ Phase 5: DNS Propagation (1-2 hours)

### **Step 5: Wait for DNS**
- [ ] Wait 15 min - 2 hours
- [ ] Check: https://www.whatsmydns.net/
- [ ] Verify domain shows Vercel IP
- [ ] Test: `https://yourdomain.com`

**Guide**: `HOSTINGER_DOMAIN_SETUP.md` (Section 5)

---

## ✅ Phase 6: Final Configuration (20 min)

### **Step 6: Update Settings**
- [ ] Update CORS in Railway backend
- [ ] Update canonical URLs in code
- [ ] Update sitemap.xml with domain
- [ ] Commit and push changes
- [ ] Verify HTTPS is working

**Guide**: `HOSTINGER_DOMAIN_SETUP.md` (Section 8-9)

---

## 🔍 Phase 7: SEO Setup (30 min)

### **Step 7: Submit to Google**
- [ ] Go to Google Search Console
- [ ] Add property (your domain)
- [ ] Verify ownership (DNS method)
- [ ] Submit sitemap
- [ ] Set up Google Analytics (optional)

**Guide**: `SEO_GUIDE.md` + `HOSTINGER_DOMAIN_SETUP.md` (Section 10)
